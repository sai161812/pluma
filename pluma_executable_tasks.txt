PLUMA — Complete List of Executable Commands & Tasks

Backend Version: Phase 13.8 (Certified Stable, 715 Passing Tests)

Input Modes: Spoken Voice or Typed Text

--------------------------------------------------------------------------------
1. AUDIO & VOLUME CONTROL (FAST Route — Instant Execution)
--------------------------------------------------------------------------------
1. "mute" / "mute audio" / "mute sound" — Instantly mutes system master volume.
2. "unmute" / "unmute sound" / "turn audio back on" — Restores system sound.
3. "volume 30" / "set volume to 30" — Sets master volume directly to 30%.
4. "set volume to fifty percent" — Sets master volume to 50% (supports spoken word numbers).
5. "turn volume to seventy" — Sets master volume to 70% from spoken voice input.
6. "volume up" — Bumps system volume up by 10%.
7. "volume down" — Lowers system volume by 10%.
8. "volume 100" / "max volume" — Sets audio to maximum level.
9. "volume 0" — Drops volume to silent (without muting).
10. "get volume status" / "check volume" / "sound status" — Queries and reports current volume % and mute status.

--------------------------------------------------------------------------------
2. APPLICATION MANAGEMENT (FAST Route — Process/App Launch & Closure)
--------------------------------------------------------------------------------
11. "open notepad" / "launch notepad" — Spawns and focuses Windows Notepad.
12. "open calculator" / "start calc" — Launches Windows Calculator.
13. "start cmd" / "open terminal" — Launches Windows Command Prompt or Windows Terminal.
14. "launch powershell" — Spawns a PowerShell terminal session.
15. "open explorer" — Launches Windows File Explorer.
16. "start edge" — Opens Microsoft Edge browser.
17. "open paint" / "launch mspaint" — Opens Microsoft Paint.
18. "launch taskmgr" / "open task manager" — Launches Windows Task Manager.
19. "open <app_name>" — Launches any registered Windows desktop application or executable in PATH.
20. "list apps" / "running applications" — Enumerates all currently running user applications with PIDs.
21. "close notepad" — Gracefully requests Notepad to terminate.
22. "close calculator" — Closes Windows Calculator.
23. "close <app_name>" — Terminates target application process safely.
24. "focus notepad" / "switch to calculator" — Brings the specified application window to the foreground.
25. "is notepad running" / "app status notepad" — Checks whether an application is actively running.

--------------------------------------------------------------------------------
3. WINDOW MANAGEMENT & DESKTOP CONTROL (FAST Route — Win32 Windowing)
--------------------------------------------------------------------------------
26. "minimize window" / "minimize active window" — Minimizes the currently focused window.
27. "maximize window" / "maximize active window" — Maximizes the currently focused window.
28. "restore window" / "restore active window" — Restores minimized/maximized window to normal bounds.
29. "minimize all" — Minimizes open desktop windows to show desktop.
30. "focus window" / "switch window" — Cycles or focuses target window.
31. "list windows" / "show open windows" — Lists all visible top-level windows with HWNDs and titles.
32. "open windows list" — Returns the complete hierarchy of active desktop windows.

--------------------------------------------------------------------------------
4. CLIPBOARD & TEXT BUFFER (FAST Route — Windows Clipboard)
--------------------------------------------------------------------------------
33. "clear clipboard" / "empty clipboard" / "wipe clipboard" — Wipes clipboard contents clean.
34. "get clipboard text" / "read clipboard" / "show clipboard" — Reads and returns plain text from clipboard.
35. "pasteboard read" / "view clipboard" — Returns current text stored in system clipboard.
36. "copy status" — Checks whether clipboard has active text content.
37. "set clipboard to <text>" — Copies specific text directly into the system clipboard buffer.

38. "list files" / "list files in current directory" — Lists files and directories in current working path.
39. "list directory contents in <folder_path>" — Enumerates files in a specific directory.
40. "find file test.txt" — Searches local directory tree for a specific file by name.
41. "find *.py" / "search file report.docx" — Pattern/glob search for matching files.
42. "locate file config.yaml" — Recursively locates matching files on the local filesystem.

44. "make folder archive" — Creates an archive directory for file sorting.
45. "move file a.txt to b.txt" / "move a to b" — Moves/relocates a file between paths.
46. "rename file old.txt to new.txt" — Renames an existing file (records rollback snapshot).
47. "rename sample.log to sample.txt" — Renames log or text file in place.

================================================================================
SAFETY & POLICY BOUNDARIES (Deterministic Rejections / Fail-Closed)
================================================================================
PLUMA includes a policy engine that actively intercepts and blocks hazardous actions:
- "rm -rf /" or "format c:" — Automatically DENIED (System destruction prevented).
- "delete system32" — Automatically DENIED (Protected directory policy).
- "shutdown laptop immediately" — Automatically BLOCKED (High-risk action policy).
- "open malicious.exe" — Automatically REJECTED by process safety gate.
- "change firewall settings" — Automatically BLOCKED (Requires elevated approval).
